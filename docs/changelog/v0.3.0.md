## เพิ่ม

- แผนที่โค้ดแบบโต้ตอบที่หน้า `/a/[id]` — กราฟความสัมพันธ์ระหว่างไฟล์ที่ลากซูมได้
  เรนเดอร์ด้วย WebGL ผ่าน sigma และจัดวางตำแหน่งด้วย ForceAtlas2
- พื้นที่ทำงานสามคอลัมน์ที่แชร์สิ่งที่เลือกอยู่ร่วมกัน — รายการไฟล์ กราฟ และแผงรายละเอียด
  เลือกจากที่ไหนก็ตาม อีกสองส่วนตามไปด้วยเสมอ
- ต้นไม้โฟลเดอร์ที่คลี่ชั้นบนสุดไว้ให้ตั้งแต่เปิดหน้า และคลี่ตามให้อัตโนมัติเมื่อเลือกไฟล์จากกราฟ
- แผงรายละเอียดของไฟล์ — ฟังก์ชันและคลาสที่ประกาศไว้พร้อมเลขบรรทัด
  ไฟล์ที่พึ่งพาไฟล์นี้ และไฟล์ที่ไฟล์นี้เรียกใช้ คลิกเพื่อกระโดดต่อได้ทั้งสองทิศทาง
- โหมดลงสีสามแบบ — ตามโฟลเดอร์ ตามภาษา และตามความสำคัญ (จำนวนไฟล์ที่พึ่งพา)
  พร้อมคำอธิบายสีข้างกราฟและคำใบ้ว่าโหมดนั้นตอบคำถามอะไร
- ค้นหาไฟล์ที่กรองพร้อมกันทั้งรายการและกราฟ ไฟล์ที่ไม่ตรงจะถูกหรี่ลงแทนที่จะหายไป
  จะได้ยังเห็นว่าอยู่ตรงไหนของโครงสร้าง
- เน้นเพื่อนบ้านเมื่อชี้หรือเลือกโหนด — เส้นและไฟล์ที่ไม่เกี่ยวจะถูกซ่อนชั่วคราว
- เส้นทาง API ใหม่: `GET /api/analyses/:id/graph` สำหรับข้อมูลกราฟ
  และ `GET /api/analyses/:id/files/detail` สำหรับรายละเอียดของไฟล์เดียว
- ตัดจำนวนโหนดสำหรับ repo ที่ใหญ่เกินวาดไหว โดยเลือกไฟล์ที่มีความสัมพันธ์มากที่สุดก่อน
  ตัดเส้นที่ปลายอีกข้างไม่ได้ถูกส่งมาด้วย และบอกผู้ใช้ตรง ๆ ว่าตัดมา
- รองรับเครื่องที่เปิด WebGL ไม่ได้ ด้วยข้อความบอกเหตุผลและรายการไฟล์ที่ยังใช้งานได้ตามปกติ

## แก้

- ค้นหาไฟล์แล้วผลลัพธ์ยังถูกซ่อนอยู่ในโฟลเดอร์ที่ปิดอยู่ ทำให้ต้องไล่คลี่เอง
  ตอนนี้ระหว่างค้นหาจะคลี่โฟลเดอร์ที่มีไฟล์ตรงคำค้นให้ทันที

## ปรับ

- ย้ายหน้าสรุปตัวเลขเดิมไปที่ `/a/[id]/report` แล้วให้ `/a/[id]` เป็นแผนที่โค้ดแทน
  เพราะสิ่งที่ผู้ใช้อยากเห็นก่อนคือภาพรวมของโครงสร้าง ไม่ใช่ตาราง
- ขยายความกว้างสูงสุดของหน้าเพื่อให้พื้นที่ทำงานสามคอลัมน์อยู่ได้พอดี
