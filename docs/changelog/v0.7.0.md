## เพิ่ม

- ลิงก์ถาวรที่ `/r/[host]/[owner]/[name]` — เปิดได้เสมอโดยไม่ต้องจำรหัสงานวิเคราะห์ที่เป็น UUID
  พาไปผลล่าสุดของ repo นั้นทันทีถ้ามีอยู่แล้ว หรือสั่งวิเคราะห์ใหม่ให้เองถ้ายังไม่เคยมี
  หน้าแผนที่โค้ดแสดงลิงก์นี้ไว้ให้คัดลอกไปแชร์ต่อได้
- ส่งออกรายงานภาษาไทยทั้งชุดเป็น Markdown ไฟล์เดียวที่ `GET /api/analyses/:id/export/report.md`
  รวมทั้งคะแนนสุขภาพ จุดร้อน วงจรพึ่งพา ข้อสังเกตด้านความปลอดภัย และชั้นความเข้าใจที่สมาชิกสั่งไว้
  (สรุปภาพรวม คำอธิบายรายโมดูล เส้นทางอ่านโค้ด) เป็นเอกสารเดียวที่ส่งต่อให้ทีมได้เลย
- วิเคราะห์ repo เดิมซ้ำเร็วขึ้นมาก — ไฟล์ที่เนื้อหาไม่เปลี่ยนจากรอบก่อนจะไม่ถูกอ่านหรือพาร์สด้วย
  tree-sitter ซ้ำเลย ใช้สัญลักษณ์ เส้นเชื่อม ข้อสังเกตด้านความปลอดภัย และแพ็กเกจภายนอกจากรอบก่อน
  แทนทั้งหมด ยิ่ง repo ใหญ่และแก้แค่ไม่กี่ไฟล์ รอบสองก็ยิ่งเร็วขึ้นมาก
- เก็บแพ็กเกจภายนอกที่แต่ละไฟล์เรียกใช้แยกไว้ต่างหาก เพื่อให้สรุปรวมยังถูกต้องครบแม้ไฟล์ส่วนใหญ่
  จะถูกข้ามการพาร์สไปในรอบวิเคราะห์ซ้ำ

## แก้

- ตารางฟีเจอร์ยังไม่เคยมีลิงก์ถาวรอยู่ในรายการเลยตั้งแต่ต้น ทั้งที่ PLAN.md วางแผนไว้ตั้งแต่ v0.1.0

## หมายเหตุอัปเกรด

- รายงานส่งออกยังไม่มีรูปแบบ PDF — `pdfkit` ที่เบาที่สุดไม่มีฟอนต์ภาษาไทย ส่วนทางที่ถูกต้อง
  (เรนเดอร์ HTML ด้วยเบราว์เซอร์จริง) ต้องเพิ่ม Chromium เข้าอิมเมจ API ซึ่งเป็นการตัดสินใจ
  ด้านโครงสร้างพื้นฐานที่ยังรอเจ้าของงานเลือกทาง — ใช้ Markdown ไปก่อนในระหว่างนี้
