## เพิ่ม

- ถาม–ตอบกับ repo เป็นภาษาไทยที่หน้า `/a/[id]/chat` — พิมพ์คำถาม ได้คำตอบพร้อมอ้างอิงไฟล์และบรรทัดจริง
  ที่ผ่านการตรวจแล้วว่ามีอยู่จริงเช่นเดียวกับชั้นความเข้าใจของ v0.5.0
- ค้นคืนบริบทด้วย `pg_trgm` — จับคู่คำถามกับชื่อไฟล์ ชื่อฟังก์ชัน และข้อความสรุปที่ทำไว้แล้วจาก v0.5.0
  เลือกทางนี้แทนเวกเตอร์ฝังเพราะสิ่งที่ต้องค้นเป็นข้อความสั้นที่ตรงตัวอักษรได้ระดับหนึ่งอยู่แล้ว
  ไม่ต้องเพิ่มคอนเทนเนอร์รันโมเดลฝังเวกเตอร์แยก (ดู ADR 0003)
- เมื่อค้นไม่เจอหลักฐานที่ตรงกับคำถามเลย ระบบตอบตรง ๆ ว่าไม่พบ แทนการเดาจากความรู้ทั่วไปเกี่ยวกับโค้ด
  ที่หน้าตาคล้ายกัน — คำตอบทุกข้อจึงมีอ้างอิงบรรทัดจริงกำกับ หรือไม่ก็ไม่มีคำตอบเลย ไม่มีข้อความลอย ๆ อยู่ตรงกลาง
- ถามต่อเนื่องได้ — คำถามใหม่เห็นบทสนทนาสามข้อล่าสุดของตัวเอง จึงอ้างถึง "มัน" หรือ "ไฟล์นั้น" ต่อจากคำถามก่อนได้
- เส้นทางอ่านโค้ดสำหรับคนใหม่ที่หน้ารายงาน — เรียงไฟล์ 7–15 ขั้นจากไฟล์พื้นฐานที่ไฟล์อื่นเรียกใช้
  ไปจนถึงจุดเริ่มโปรแกรม ด้วย topological sort บนกราฟการนำเข้าจริง ไม่ใช่ให้โมเดลเดาลำดับ
  โมเดลมีหน้าที่แค่อธิบายว่าทำไมแต่ละขั้นถึงควรอ่านตอนนั้นและควรสังเกตอะไร
- ไฟล์ที่พึ่งพากันเป็นวงจร (ไม่มีลำดับที่ถูกต้องแท้จริง) ยังปรากฏในเส้นทางอ่านโค้ด ไม่ใช่หายไปเงียบ ๆ
- เส้นทาง API ใหม่สี่เส้น: ถามคำถาม, ดูประวัติบทสนทนา, สร้างเส้นทางอ่านโค้ด, ดูเส้นทางล่าสุดที่เคยสร้างไว้
- เพดานจำนวนครั้งต่อชั่วโมงแยกกันสำหรับถาม–ตอบและเส้นทางอ่านโค้ด เช่นเดียวกับงานสรุปของ v0.5.0
  เพราะทั้งสองเรียกโมเดลด้วยกุญแจของผู้ใช้เอง

## แก้

- ตารางฟีเจอร์ยังบอกว่าถาม–ตอบและเส้นทางอ่านโค้ดเป็นของที่ยังไม่มี ทั้งที่ปล่อยไปแล้วในรุ่นนี้

## ปรับ

- ดึงตัวตรวจ "กุญแจผิดต้องหยุดทันที" ของชั้นความเข้าใจออกมาเป็นฟังก์ชันกลางใน `@repolens/ai`
  เพราะตอนนี้มีสามฟีเจอร์ (สรุป, ถาม–ตอบ, เส้นทางอ่านโค้ด) ที่ต้องเช็กเรื่องเดียวกัน
